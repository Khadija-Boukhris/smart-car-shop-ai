# Frontend React - Voiture Shop

## Lancement

1. Lancez d'abord le backend Spring Boot sur `http://localhost:8080`.
2. Ouvrez un terminal dans ce dossier : `src/main/webapp/reactjs`.
3. Installez les dépendances :

```bash
npm install
```

4. Lancez React :

```bash
npm start
```

5. Ouvrez : `http://localhost:3000`

## Fonctionnalités

- Page d'accueil
- Navigation Bootstrap
- Liste des voitures
- Ajout voiture
- Édition voiture
- Suppression voiture
- Toast de succès
- Axios pour communiquer avec Spring Boot
